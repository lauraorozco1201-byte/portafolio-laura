Proyecto de packaging

GOMYS

Diseño de packaging para una marca ficticia de gomitas con temática marina.

🐙
✳ Sobre el proyecto

Concepto

Desarrollo de un packaging para una marca ficticia de gomitas con temática marina. El objetivo fue crear una identidad visual llamativa y un empaque funcional que transmitiera una imagen divertida y atractiva.

Mi aporte al proyecto

Mi participación

Este proyecto fue desarrollado en equipo. Mi participación se centró en el diseño del troquel estructural y del empaque interno en Adobe Illustrator, preparando la base técnica para la aplicación del diseño gráfico.

🐙
02 / Sistema de empaque

Empaque externo e interno

Para este proyecto se desarrollaron dos elementos de empaque que funcionan en conjunto. El empaque externo corresponde a la caja, mientras que el interno está compuesto por las bolsas individuales que contienen las gomitas.
